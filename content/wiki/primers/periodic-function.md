A function f is periodic with period T if f(x + T) = f(x) for every x: shift
the input by T and the output repeats exactly. The graph is a single motif of
width T stamped end to end along the whole axis. Sunrise times, alternating
current, and a plucked string's displacement are all periodic in time.

One consequence does real work here: a periodic function is completely
determined by its behaviour on any one interval of length T, so any honest
computation about it — an average, an area — need only look at a single
period, and it does not matter which one.
