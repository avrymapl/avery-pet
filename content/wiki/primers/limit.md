A limit captures the value a quantity is heading toward, as opposed to any
value it actually takes. The sequence 0.9, 0.99, 0.999, … never reaches 1,
but 1 is the one number the terms approach as closely as you please, and so
we say the sequence has limit 1.

The definition makes "approach as closely as you please" exact: L is the
limit if, for any tolerance you set around L, the quantity eventually stays
within that tolerance forever after. The power of the idea is that it assigns
a precise value to processes that never finish — an infinite sum, an
ever-finer subdivision — and every concept built on it inherits that
precision.
