A function is a rule that takes an input and returns exactly one output. The
notation f(x) names the output that the rule f assigns to the input x. The
rule can be given by a formula, a graph, a table, or plain words — what makes
it a function is only the guarantee that each input yields one definite
output.

It helps to keep the function itself distinct from any one of its values:
f is the whole rule, f(x) is a single number. Much of mathematics consists of
treating the rule as an object in its own right — comparing functions, adding
them, transforming one into another — and everything here does exactly that.
